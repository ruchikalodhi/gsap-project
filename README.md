## ⚡ Tech Stack

* **[GSAP](https://gsap.com/)** — **The Motion Engine.** Drives the entire visual experience via scroll-linked timelines, pin-based scenes, SplitText typography reveals, and custom parallax effects.
* **[React](https://react.dev/)** — **UI Architecture.** Modular component structure engineered to manage complex animation states, lifecycle-safe GSAP contexts, and responsive UI layouts.
* **[Tailwind CSS](https://tailwindcss.com/)** — **Utility-First Styling.** Rapid, zero-overhead layout design and responsive utility styling tailored for precision UI placement.
* **[Vite](https://vitejs.dev/)** — **Next-Gen Tooling.** Instant HMR and ultra-fast production builds, keeping feedback loops immediate while developing heavy animation sequences.

---

## 🔥 Key Features

* **🎭 SplitText Typography** — Impactful character/word reveals on enter, powering cinematic hero sections and title headers.
* **📜 ScrollTrigger Master Timelines** — Multi-section animation orchestration perfectly synced to native user scrolling.
* **🎥 Frame-Synced Video Playback** — Scroll-bound video scrubbing for an immersive, interactive storytelling experience.
* **🖼️ Dynamic Image Masking** — Pin-and-reveal image masks driven by viewport progress.
* **🎢 Depth Parallax & Pinned Scenes** — Layered background movement and locked viewport frames that keep key content sticky.
* **🎠 Custom GSAP Carousel** — Fully animated, multi-input carousel with smooth physics and custom navigation logic.
* **📱 Fully Responsive Motion** — Adaptive animation timelines that adjust, scale, or disable seamlessly across desktop and mobile.

## <a name="quick-start">🤸 Quick Start</a>

Follow these steps to set up the project locally on your machine.

**Prerequisites**

Make sure you have the following installed on your machine:

- [Git](https://git-scm.com/)
- [Node.js](https://nodejs.org/en)
- [npm](https://www.npmjs.com/) (Node Package Manager)

**Cloning the Repository**

```bash
git clone https://github.com/adrianhajdin/gsap_cocktails.git
cd gsap_cocktails
```

**Installation**

Install the project dependencies using npm:

```bash
npm install
```

**Running the Project**

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to view the project.
